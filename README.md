# 🚀 Todo App (Full Stack DevOps Project)

## 🔧 Tech Stack
- React.js (Frontend)
- Node.js + Express (Backend)
- PostgreSQL
- Docker
- Kubernetes (Minikube)
- Vercel (Frontend Deployment)

## ✨ Features
- Add Task
- Update Task
- Delete Task

## 🌐 Live Demo
https://my-todo-app-nine-liart.vercel.app

## 📦 How to Run
1. Start minikube
2. Apply Kubernetes YAML
3. Port-forward service
4. Run React app
